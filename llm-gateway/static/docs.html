hosub LLM 게이트웨이 — API 탐색기

서비스 토큰을 넣으면 그 토큰 기준으로 생성된 지금의 계약이 열린다. 쓸 수 있는 역할과 현재 걸린 모델만 보인다.

개발용 탐색기다.
  • 토큰은 이 브라우저 탭에만 남는다(sessionStorage). 서버에 저장하지 않는다.
  • 프로덕션 코드에서는 브라우저에 토큰을 넣지 말 것. 소비자 코드는 자기 서버 사이드 라우트에서만 게이트웨이를 부른다.
  • Try it out 은 실제 요청이다 — 분당 레이트리밋을 소모하고 맥의 GPU 를 쓴다.
  • 파이썬이라면 스펙으로 클라이언트를 생성하기보다 GET /v1/client/llmgw.py 를 받는 편이 낫다.
