# 원장·매매일지 정합성 수정 (2026-11-07)

부분 청산 후 잔량으로 이동한 매수 수수료를 원거래와 분리해 누락하던 문제를 수정한다. 동일 환경·종목·가격·잔량 수량을 만족하는 단일 선행 거래만 연결하고, 모호한 경우 미확인으로 유지한다. parent_position_id는 거래 계보이며 주문 집행 동작을 변경하지 않는다.

증권사 순손익은 비용을 다시 빼지 않는다. 건별 비용 검증과 비용 전/실제 비용/설정 비용 가정 비교를 제공하며, 계좌와 원장 차액은 미배분으로 남긴다. 설정 비용 가정은 현재 설정 요율을 사용하고 체결가에 이미 포함된 슬리피지를 이중 차감하지 않는다. 증권사 체결 시뮬레이션을 실제 거래 성과로 간주하지 않는다.

일지는 날짜 조건으로 전체 원장을 조회한다. 과거 일지 재대사는 그 날짜의 저장 체결만 사용한다. 청산 기록이 없어도 증권사 손익이 있는 날은 기간 합계에 포함한다. 화면에 실제 매도 수량과 검증 상태를 표시한다.

배포 전 SQLite backup API로 trading.db와 backtest.db를 백업하고 journal 디렉터리를 복제한다. 거래 서비스 정지 중 확인 가능한 잔량 계보를 연결하고 실비용을 재계산한다. 저장 일지를 다시 생성하고 기존 LLM 요약은 이전 백업에 보존한 뒤 새 수치 기반 사실 요약으로 교체한다. 원장/계좌 미배분 차액은 숨기거나 특정 기법에 강제 배분하지 않는다.

복사본 검증: 잔량 6건 연결, 매수 수수료 17,659.3원 배분. 11/6 차액 -1,048원 잔존. 과거 11/2~3 미확인 비용 존재. 이 값들은 원자료 추가 대조가 필요한 제한이며 0으로 위장하지 않는다.
