# 알려진 유보 결함 — 재검토 조건 포함

정밀 진단(2026-08-01)에서 확인했지만 **의도적으로 고치지 않은** 것들.
개선 후보를 찾을 때 여기서 시작하되, 각 항목의 유보 사유가 여전히 유효한지
먼저 확인할 것. 심각(H)·중간(M) 등급 중 수정된 것들은 PR #250 참조.

## 저위험 (재확인 완료 — 종전 판단 유지)

- **dwell 기산점이 감시목록 편입 시각** — tier 변경 시각이 아니라서 tier 간 이동
  직후 회전 대상이 될 수 있다. 실효 영향 미미
- **회전 판정의 신호 조회 창이 7일 고정** — silent_dwell 과 독립인 매직넘버
- **collect 모드에서 drop 결정 보류** — collect 는 과도기 모드였고 현행은 full
- **장외 시간 강등 보류가 승격은 막지 않는다** — 의도된 비대칭(마감 후 강등 금지의 반쪽)

L급 경미 3건(L2/L5/L6)은 코드 주석에 위치와 함께 기록돼 있다 — 동작 영향 없음.

## 시스템 일반

- **잔차 IC → 실현 R 환산 불가** 가 현행 설계의 기둥이다. 랭킹·가중치·ML 을
  다시 도입하려면 [measurement.md](measurement.md)의 폐기 근거를 먼저 반박할 것
- **desk 손절·익절 라인 갱신 규칙은 훅만 있다**(`update_lines`) — 규칙은 사용자
  지정 대기. 재료는 breakeven shadow·trailing 측정이 축적 중
- **shadow 모드의 의미 변화** — full 흡수 이후 shadow 는 '기존 경로 복귀'가 아니라
  '감시목록 동결'이다. 롤백 수단으로 쓸 때 이 차이를 알아야 한다
- 프리마켓·NXT, 매물대, VPIN, 다이버전스, 문서식 급증은 **관측 전용** — 판정 전에
  신호·주문 경로에 넣지 않는다(각 파일 docstring 의 사전 질문 참조)
