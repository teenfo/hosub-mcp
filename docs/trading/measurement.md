# 측정 거버넌스 — 판정 원칙과 측정 결과 전체

이 시스템의 발전 사이클은 **구현 → 측정 → 유지/폐기**다. 무언가를 바꾸기 전에
이 문서를 읽을 것 — 지금 코드에 없는 것들 상당수는 **측정으로 폐기된 것**이고,
다시 만들면 같은 대가를 치른다.

## 판정 원칙 (어길 때마다 대가를 치렀다)

1. **측정이 있는가** — 없으면 값을 정하지 말고 관측 경로부터 만든다
2. **판정 기준을 미리 못박았는가** — 결과를 본 뒤 기준을 바꾸면 그 측정은 버린다.
   바꿔야 했다면 그 사실을 명시하고 더 보수적인 쪽으로만
3. **대조군은 변동성 정합 무작위** — 단순 무작위 대조군은 부족하다. 선정 방식이
   변동성을 편향시키면(대부분 그렇다) 같은 날·최근접 `atr_pct` 무작위와 비교해야
   선정 자체의 가치가 드러난다. 2026-08-01 두 측정에서 단순 대조군의 결론이
   뒤집혔다(아래 표)
4. **유의성 검정 없이 격차만 읽지 않는다** — 다중 비교면 본페로니
5. **유니버스 오염 주의** — 연구 하네스에 ETF 가 섞여 실전(제외)과 달랐고, 두
   측정을 서로 반대 방향으로 왜곡했다. 하네스와 실전의 유니버스를 맞출 것
6. **되돌릴 수 있는가** — 런타임 오버라이드로 끌 수 있으면 먼저 켜보고 정한다
7. **틀렸을 때 실거래에 닿는가** — 닿으면 기본값을 보수적인 쪽으로

### 국면 입력 불일치일 — 사전 등록 (2026-08-05, 표본 축적 중)

배경: 8/4·8/5 이틀 연속 **night_bias 강세 vs 전일 breadth 약세** 불일치일에
큰 손실(−8,578 / −13,825 진행중). 두 날 모두 개장 직후 진입이 전멸했는데,
원장 전수 확인 결과 **시간대 자체는 무죄** — 09:40 이전 진입은 7일 전체로
평균 −0.33%로 이후 진입(−0.50%)보다 오히려 낫고, 정상 판정일(7/29·7/30·
8/3)의 개장 직후는 플러스였다. 손실은 전부 불일치일에 몰렸다.

**측정 (기준 사전 확정 — 결과를 본 뒤 바꾸면 폐기):**
- 불일치일 정의: regime_log 에서 그날 첫 판정 기준 night_bias 와 base_regime
  의 SIGN 이 반대(강세 vs 약세). 중립 포함 조합은 불일치가 아니다.
- 지표: 불일치일 vs 일치일의 (a) 롱 실현손익 평균 %·건수 (b) 개장 직후
  (09:40 이전 진입) 성적 (c) 인버스 신호·성적. 표본 각 ≥15일, t≥2.
- **공변량 — 개장 피크·되돌림 깊이** (사용자 관찰 2026-08-05, 8/4 실측
  +2.48%→+0.73%): bars 수집 종목(≈800)의 '시가 대비 중앙값'으로
  `피크 = max(09:20~09:35)`, `되돌림 = 피크 − 10:00 값`. 기존 분봉에서
  파생(추가 수집 0). 불일치일과 되돌림 깊이의 상관을 함께 본다 —
  성립하면 게이트는 시간이 아니라 **불일치일 조건부**로 설계 제안.
- 통과 시 제안(적용은 사용자 결정): 불일치일 보수 모드 — 국면 연동 규칙
  (momentum 활성 등)을 중립 취급, 리스크 축소. 미통과면 폐기 기록.

### 타임아웃 청산 반사실 — 1차 실측, 판정 보류 (2026-08-05)

배경: 사용자 지적 "타임아웃 손절도 손봐야 할 것 같다". 타임아웃 29건(전 기간)

  - 6건은 목표 도달(최대 미래산업 −117 → +3,074 — **한 건이 격차의 18%**),
    9건은 마감까지 소폭 회복

**사전 등록**: 표본 40건 도달 시 판정 — (반사실 − 실제) 평균이 양수·t≥2 면

규칙별 분해 병행(vwap_reclaim 10건·orb 6건이 최다). 슬롯 기회비용(자리를
